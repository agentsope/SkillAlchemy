# Quality checklist

C06/C07 authored evaluation convention. These checks are requirements until actual evidence is retained. No numeric score here is an evidence-derived creative threshold. Record pass/fail/warning/not_executed/not_applicable/unknown for each dimension, with evidence and scope.

| Dimension | Static coverage | Actual observation needed |
|---|---|---|
| narrative_clarity | Brief/message/copy coherence | View the cut for comprehension; no universal genre formula |
| visual_consistency | Style tokens and asset ledger | Inspect actual frames for consistency |
| pacing | Time budget closes | Full-motion viewing of the whole cut |
| animation_quality | Declared time/frame derivation | Repeated/reordered samples and actual full motion |
| text_legibility | Copy, font size/layout plan | Actual visible frames, consecutive cue/transition frames |
| factual_accuracy | Supplied/sourced facts, derivations, unknown labels | Literal-value scan and rendered visible text |
| audio_quality | Audio intent, asset permissions, unit/alignment metadata | Actual track/listening; missing requested narration stays unfinished |
| technical_correctness | Exact pin, namespaces, timing conversion | Actual encoded file/probe, resource/layout observations |
| reproducibility | Source/lock/version/commands retained | Reproduce only the tested path/scope |

- [ ] Preserve explicit duration/orientation/audio/language constraints and label reversible package defaults.
- [ ] Separate user/sourced facts, unknowns and synthetic placeholders; no invented product/scientific/documentation claims.
- [ ] Verify shot closure and the selected engine's seconds/frames/milliseconds and index/range conventions.
- [ ] Probe actual tools/exporter and intended-use eligibility; unknown Remotion v4 production eligibility is not eligible.
- [ ] Keep HF, Remotion server/browser, Motion Canvas and source-bound Canvas/WebGL APIs isolated.
- [ ] Keep asset, engine, codec/binary, provider and intended-use rights independent; no unlicensed media or dependency binaries in distribution.
- [ ] Retain static check logs, actual preview/frame evidence and actual encoded-file probe separately.
- [ ] Check actual consecutive transition/caption frames where relevant; still samples do not establish continuous pace.
- [ ] For pending narration retain provisional timing, incomplete audio QA and no claimed alignment/listening.
- [ ] Repair actual observed defects against the authored brief or an admitted recovery within its exact scope; retain before/after evidence and rerun affected checks.
- [ ] Report all eleven C07 states independently with evidence/limitations; no code/preview/build is relabeled an encoded video.

The P35 static-versus-motion cases and historical P36 Motion Canvas incidents remain context-bound notes. This C-authored checklist does not promote their film-local thresholds or historic defects into universal rules.
